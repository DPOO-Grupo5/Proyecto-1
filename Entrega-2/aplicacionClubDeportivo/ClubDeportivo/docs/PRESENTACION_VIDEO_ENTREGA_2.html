Prueba de serialización

Prueba de consola

Se inició la aplicación dos veces con un archivo de datos temporal: el resumen conservó 2 usuarios, 1 equipo y 1 producto.

Qué significa

La persistencia está comprobada. La consola no mostró una operación de alta seguida de reinicio en la prueba grabada.

La prueba temporal no modifica los datos de entrega. En la grabación, muestra solo cuentas de demostración y evita exponer credenciales reales.

04 · Guion de grabación

Pasos concretos para capturar

  1. Abre el proyecto en Eclipse y ejecuta Consola con el almacén temporal preparado.
  2. Entra como administrador de demostración; enseña el resumen y la opción de crear usuario. No hace falta guardar un alta para esta toma.
  3. Cierra sesión y entra como socio de demostración; enseña el resumen individual.
  4. En una segunda toma, inicia sesión como entrenador y fisioterapeuta para mostrar el resumen disponible de cada perfil.
  5. Enseña la salida registrada de VerificacionEntrega (8/8) para reglas y persistencia; aclara que es un verificador aparte.
  6. Cierra con una diapositiva de alcance: consola funcional y lógica comprobada; varias operaciones de dominio aún no están en los menús.

Si las credenciales demo no están disponibles, consúltalas en el README local antes de grabar; no inventes usuarios ni resultados.

05 · Correspondencia y límites

Contar lo que existe con precisión

Demostración de consola: login, resumen, cambio de contraseña y creación de usuario por administrador.
Prueba automatizada: autenticación, capacidad, conflictos de reserva, stock, impuesto y guardar/cargar estado.
Solo inspeccionado en código: operaciones de dominio de entrenador, fisioterapia, competencias y otras acciones sin acceso desde el menú actual.
Ojo con los diagramas: hay mensajes y nombres de método que no coinciden exactamente con el código actual; no los uses como prueba de ejecución.

No afirmar que se muestran competencias o puntos de fidelidad conformes a la regla del 2%: hay diferencias documentadas entre diseño y código.
